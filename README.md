# No Bico

**Slogan:** Serviço garantido, pagamento seguro 🔒

Resumo do projeto: No Bico é uma plataforma que conecta profissionais liberais (diaristas, encanadores, técnicos) a clientes de forma segura: o cliente deposita o valor em garantia (escrow) e o pagamento só é liberado quando o serviço é confirmado como concluído com sucesso. O profissional só paga uma porcentagem quando o serviço é finalizado e o pagamento é liberado.

Entregáveis neste repositório:
- `docs/` — documentação detalhada (sitemap, copy, fluxos, segurança, avaliações, stack, gamificação)
- `wireframes/` — wireframes em SVG (baixa fidelidade) para desktop e mobile
