# Stack Tecnológica (recomendado para 2026)

- MVP No-code: Bubble ou FlutterFlow + Zapier/Make
- Full-code (escala): Next.js + React + TypeScript (frontend), React Native ou Flutter (mobile), Node.js (NestJS) ou Go (backend)
- DB: PostgreSQL + Prisma/TypeORM
- Realtime: Redis, WebSockets (Pusher/Supabase Realtime)
- Infra: Docker, Kubernetes ou Vercel/Fly + AWS/GCP
- Observability: Sentry, Prometheus/Grafana, OpenTelemetry
- Auth: OAuth2/JWT/NextAuth, 2FA opcional

APIs (Brasil) recomendadas para retenção/escrow:
- Pagar.me (split/payments)
- Asaas
- Gerencianet
- Juno
- PagSeguro
